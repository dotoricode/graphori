# Contributing

Small, evidence-backed changes are welcome. Open an issue or discussion before changing product boundaries, execution safety, or public claims.

1. Keep the change scoped and preserve existing user work.
2. Add or update tests for behavior changes.
3. Run `python -m unittest discover -s tests -v` and `python scripts/validate_docs_indexes.py`.
4. Do not add generated benchmark results, provider credentials, or claims that cannot be reproduced from the repository.
5. Describe limitations and the checks you actually ran in the pull request.
