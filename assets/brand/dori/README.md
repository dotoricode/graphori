# Dori character assets

Dori is Graphori's acorn operations engineer: calm, selective, and responsible for the final verification node. The character is intentionally not a robot, swarm, terminal glyph, cowboy, or derivative of the visual reference used to set the pixel-art quality bar.

- `dori-master.png`: 1254×1254 generated key art on a dark background.
- `dori-256.png`: repository/avatar crop.
- `dori-64.png`: small UI crop.

The images were generated with OpenAI's built-in image generation tool on 2026-08-27 from a project-authored prompt. A user-supplied image influenced only the requested density, lighting, and retro pixel-art finish; the prompt explicitly excluded its species, anatomy, costume, pose, and accessories. Generated imagery may not be legally exclusive, and similarity cannot be ruled out by generation alone. Review before trademark or merchandise use.
