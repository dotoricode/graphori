# Graphori v1과 v2 비교 방법

측정일: 2026-08-24

이 문서는 시험을 시작하기 전에 비교 조건을 고정하려고 작성했다. 결과를 본 뒤
v2에 유리하게 규칙을 바꾸지 않았다.

## 무엇을 비교했나

두 버전에 **같은 코딩 과제**를 시키고 다음 내용을 비교했다.

- 정답을 만들었는가
- 완료까지 얼마나 걸렸는가
- AI를 몇 번 불렀는가
- 입력과 출력에 얼마나 많은 토큰을 썼는가
- 허용하지 않은 파일을 바꾸지 않았는가
- “완료했다”는 보고와 실제 결과가 일치하는가

v1은 과거 실행 기록을 다시 튼 것이 아니다. 당시 실행 원본이 남아 있지 않기
때문에 비공개 개발 이력의 revision `93c5fcf`에 적힌 작업 규칙을 옮겨 재현했다.
이 revision은 깨끗한 공개 이력에서는 도달할 수 없다. v2는 측정 당시 로컬에 있던
실행기를 사용했다.

## 무엇이 같았나

- 같은 작업 설명
- 같은 시작 파일과 공개 테스트
- 같은 숨은 최종 검사
- 같은 Codex 모델과 보통 수준의 검토 강도
- 같은 파일 권한과 240초 제한
- 매번 새 Git 저장소와 새 AI 대화 사용
- 과제와 버전 조합마다 두 번씩 실행
- 정해진 씨앗값 `20260824`로 실행 순서를 섞음
- 숨은 검사는 작업이 끝난 뒤에만 공개

## 무엇이 달랐나

비교하려던 차이는 운영 방식 하나다.

- v1: 제작 AI가 일한 뒤, 다른 검토 AI가 한 번 더 확인한다.
- v2: 제작 AI가 일한 뒤, 미리 정한 자동 검사가 확인한다.

따라서 AI가 받은 전체 안내문이 글자까지 완전히 같지는 않다. 작업 내용과 환경은
같지만, 각 버전이 일을 관리하는 방식은 의도적으로 다르다.

## 사용한 과제

1. `normalize-tags`: 문자열을 정리하고 중복을 제거하는 한 파일 작업
2. `config-parser`: 여러 입력 규칙을 확인하는 JSON 설정 읽기 작업

공개 테스트는 기본 동작만 확인했다. 숨은 검사는 작업 설명에 적혀 있지만 공개
테스트에 없는 경계 상황도 확인했다.

## 결과를 읽을 때 주의할 점

- 버전마다 실행이 네 번뿐이라 모든 종류의 개발 작업으로 일반화할 수 없다.
- 네 번 모두 맞았다는 결과가 두 방식의 품질이 언제나 같다는 뜻은 아니다.
- 실행 중 문제가 생겨도 몰래 다시 돌리지 않고 원본 결과에 남긴다.
- 결과는 기록된 모델, 도구 버전, 과제와 이 컴퓨터 환경에만 해당한다.
- v2는 당시 아직 커밋하지 않은 후보였으므로 정식 출시 버전이라고 부르지 않는다.
