### Release-blocking defects fixed during acceptance

- Claude-only discovery could not route implementation work because Sonnet's
  runtime entry omitted the already-live-tested coding capability. Sonnet now
  supports coding with `benchmark_confidence=partial`; no benchmark score is
  fabricated, and a scored candidate still takes precedence when available.
- Cold resume now advances every safely-ready descendant, stops at a gate or
  no-progress boundary, and always releases writer ownership.
- Doctor no longer calls every non-terminal journal resumable. Blocked, failed,
  cancelled, and outcome-unknown projections require human review.
- Python bytecode side effects are suppressed in bounded provider/verifier
  subprocesses so verification does not violate the declared write scope.
