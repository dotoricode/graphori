# doctori evidence 색인

이 폴더는 Doctori에서 가져온 비교 증거를 원본 의미와 함께 보존한 사본입니다. `MANIFEST.md`는 파일 크기와 digest 비교표이고, `PROCESS.md`와 `WORK_DURATION_ANALYSIS.md`는 원본 기록입니다.

- `MANIFEST.md`: 보존 파일 목록과 SHA-256 비교
- `PROCESS.md`: Doctori 작업 과정
- `WORK_DURATION_ANALYSIS.md`: 작업 시간 분석
- `decisions/`: Doctori 결정 기록
- `verification/`: Doctori 검증 기록
