# ADR 0005: 오케스트레이터는 위임과 종합만 수행한다

- 상태: 채택
- 날짜: 2026-08-08

## 결정

이미지 생성이 완료된 뒤 오케스트레이터는 저장소 파일을 직접 작성하거나 코드를 구현하거나 테스트를 실행하지 않는다. 오케스트레이터는 기획, 작업 배정, 진행 확인, 결과 종합만 담당한다.

사용자가 추가 작업을 요청해도 이미 진행 중인 작업은 중단하지 않는다. 가능한 팀에 새 멤버를 고용해 병렬로 처리한다. 팀별 멤버는 최대 2명, 전체 동시성 한도는 오케스트레이션 설정을 따른다.

## 이유

작업을 맡은 멤버가 구현과 검증의 책임을 분명히 지고, 진행 중인 결과가 덮어써지거나 중단되는 일을 막기 위해서다. 팀 수와 동시 실행 수를 제한하면 검토 가능한 작업 흐름을 유지할 수 있다.

## 영향

구현·문서 작성·테스트는 항상 배정된 멤버가 수행한다. 오케스트레이터는 멤버의 결과와 검증 근거를 모아 계획에 반영하며, 멤버가 없거나 동시성 한도에 도달하면 새 작업을 배정하지 않고 상태를 보고한다.
