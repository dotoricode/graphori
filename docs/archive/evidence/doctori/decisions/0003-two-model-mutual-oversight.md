# 결정 0003: 두 모델이 서로 감시하는 방식

- 상태: 승인됨
- 날짜: 2026-08-08

## 결정

1팀과 2팀은 일을 절반씩 나누는 팀이 아닙니다. 같은 중요한 결과를 서로 다른 모델이 독립적으로 살펴보는 감시 쌍입니다.

- 1팀은 Codex를 사용합니다.
- 2팀은 Claude Code를 사용합니다.
- 한 팀이 먼저 만들 수 있지만, 다른 팀이 같은 결과를 확인하기 전에는 기획팀이 최종 승인하지 않습니다.
- 두 팀의 결론이 다르면 둘 다 기록하고 기획팀이 근거를 비교해 결정합니다.
- 서로의 문장을 그대로 따라 쓰지 않습니다. 각자 원본 자료와 실제 파일을 보고 판단합니다.

## 왜 이렇게 하나요?

한 모델이 놓친 문제를 다른 모델이 찾을 수 있기 때문입니다. 두 팀이 서로 동의했다는 사실보다, 서로 다른 방법으로 확인하고도 같은 결론에 도달했는지가 더 중요합니다.

## 앞으로의 적용

- 설계: 한 팀이 만든 설계를 다른 설계팀이 감시합니다.
- 검증: 두 검증팀 모두 전체 설계와 구현을 독립적으로 검사합니다.
- 구현: 한 모델이 작성한 중요한 코드는 다른 모델의 검사를 통과해야 합니다.
- 진행판에는 작성한 팀과 감시한 팀을 함께 표시합니다.
