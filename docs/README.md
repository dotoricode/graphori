# docs 문서 색인

이 폴더는 Graphori의 설계, 결정, 조사, 검증 기록과 Markdown viewer를 담습니다. 계획은 계획으로, 실제 실행 결과는 검증 기록으로 읽습니다.

- `IMPLEMENTATION_PLAN.md`: 전체 구현 단계와 완료 조건
- `PROCESS.md`: PR #2 진행 계획·변경·검사·남은 일
- `DOCS_VIEWER.html`: 상대경로 Markdown viewer
- `PROCESS_VIEW.html`: `PROCESS.md` viewer로 이동하는 페이지
- `GRAPHORI_FUNCTION_GUIDE.md`: 현재 실행 기능과 설계 기능을 구분한 쉬운 설명
- `GRAPHORI_LEARNING_GAME.html`: 실제 실행 결과를 보며 Graphori를 배우는 참여형 게임
- `public/`: 공개 베타의 제품 안내, 신뢰 모델, 제한 사항, 이력, 쇼케이스 계약
- `architecture/`: 시스템과 이벤트 계약
- `decisions/`: 중요한 정책 결정
- `design/`: 제안과 설계 비교
- `research/`: 조사와 근거
- `verification/`: 실제 검증·리뷰 결과
- `evidence/doctori/`: 보존된 Doctori 비교 증거
