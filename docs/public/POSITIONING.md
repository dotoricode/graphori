# Positioning: why this slogan

## Fewer agents. Every result verified.

“Plan, execute, verify,” “local-first,” “replayable,” and “fewer agents” are useful product facts, but they are not a distinctive position. Current coding-agent tools already use those ideas: [OSpec](https://github.com/clawplays/ospec) describes a verifiable plan/act/verify loop, [Agentplane](https://github.com/basilisk-labs/agentplane) emphasizes local reviewable evidence, [agent-handoff](https://github.com/WillowRyu/agent-handoff) uses disk-backed plan/execute/verify stages, and [Agent-Blackbox](https://github.com/TaewoooPark/Agent-Blackbox) offers replayable operational graphs.

Graphori's narrower claim is allocation discipline plus verification. An additional agent is not a feature by itself; it must create enough independent value to belong in the graph. The journal then records whether each result actually reached a verified state.

The supporting line is:

> Graphori plans coding work as a graph, runs only the agents it needs, and verifies the result.
