# Showcase

The showcase does not substitute imagined product screens for evidence. `examples/` holds commands that can be run locally. `assets/brand/` contains Dori's original key art, README hero, and GitHub social-preview base.

Dori is an acorn operations engineer carrying a five-node graph board whose last node is verified. The art deliberately avoids robots, swarms, and terminal-dot mascots. Its provenance and limitations are documented beside the files. Add a product screenshot only with the command, commit, locale, and fixture/run ID that produced it.
