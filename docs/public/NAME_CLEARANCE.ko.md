# 이름과 슬로건 검색

2026-08-27에 확인했습니다. 이 문서는 공개 준비를 위한 실무 검색 기록이며 법률 의견이나 상표 사용 가능성 보장이 아닙니다.

## 정확한 이름 확인

- GitHub 저장소 검색에서 정확한 `graphori` 이름은 현재 private 저장소만 확인됐습니다. Graphoria, Graphorin, Graphoris처럼 철자가 비슷하지만 다른 이름도 있었습니다.
- PyPI는 `graphori`와 `graphori-core` 모두 HTTP 404를 반환했습니다. 확인 시점에는 정확히 같은 프로젝트 이름이 등록되지 않았습니다.
- 정확한 슬로건 `Fewer agents. Every result verified.`를 웹에서 검색했지만 같은 제품 문구는 찾지 못했습니다.

## 상표 판단의 경계

[USPTO 상표 검색](https://tmsearch.uspto.gov/search/)과 [WIPO Global Brand Database](https://www.wipo.int/en/web/global-brand-database/index)는 법적 검색을 시작하는 공식 자료입니다. 이번 검색에서는 다른 상품 분야의 유사 철자는 확인했지만, 모든 국가와 소프트웨어 분류에서 법적 사용 가능성을 증명하지는 못했습니다.

상업적 상표 등록, 유료 홍보 또는 법적 사용 가능성 주장을 하기 전에는 대상 국가에 맞는 전문 상표 조사를 별도로 진행해야 합니다.
