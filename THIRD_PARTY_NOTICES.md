# Third-party notices

Graphori's Python runtime currently declares no third-party runtime dependency in `pyproject.toml`.

Bundled font assets retain their upstream licenses:

- `assets/fonts/IBM-Plex-Sans-KR-*.woff2`: IBM Plex Sans KR; see `assets/fonts/IBM-Plex-Sans-KR-LICENSE.txt`.
- `assets/fonts/SUIT-Variable.woff2`: SIL Open Font License 1.1; see `assets/fonts/SUIT-OFL-1.1.txt`.

Release verification tools are installed into an isolated temporary environment and are not redistributed by this repository. Release artifacts include an SBOM generated from the built distribution.
